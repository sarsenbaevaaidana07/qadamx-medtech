Сайт: https://qadamx-medtech-research-1109.happyburr1.chatgpt.site

ЧТО РАБОТАЕТ
Гостевой кабинет без регистрации отправляет учебную заявку назначенному врачу.
Секретный код открывает только статус и ответ. Сам текст заявки публично не выдаётся.
Врач, студент и наставник входят по отдельным логинам/паролям без ChatGPT.
Пароли не включены в исходники или архив.
Документы, неизменяемые версии, назначения наставников, уведомления и заявки
хранятся в серверной базе D1. Проверка доступа выполняется для каждой записи.
Врач назначает наставника студенту; только этот наставник видит отправленную работу.
Студент сохраняет и отправляет работу; наставник возвращает комментарий или зачёт.
Уведомления сохраняются на сервере; интерфейс проверяет их каждые 15 секунд,
когда пользователь не редактирует запись. Это уведомления внутри сайта, не SMS/push.
Конфликты версий отклоняются сервером. Старые локальные архивы не удаляются;
их можно явно перенести из настроек после подтверждения учебного состава.
Локальная запись микрофона до 60 секунд, прослушивание/скачивание/удаление.
Аудио остаётся в браузере и не превращается автоматически в текст.

ОТДЕЛЬНЫЕ КАБИНЕТЫ
Врач: приёмы, медицинские записи, заявки пациентов, назначение наставников.
Студент: задания, библиотека, учебные записи, обратная связь назначенного наставника.
Наставник: очередь назначенных студентов, проверка, комментарии и учебный результат.

ЧТО ЕЩЁ ТРЕБУЕТ ПОДКЛЮЧЕНИЯ
AI и распознавание речи: API-проект с разрешённым доступом/бюджетом.
ИИН и подтверждение телефона: SMS-провайдер и доверенная проверка связи ИИН/телефона.
Сам SMS-код доказывает доступ к номеру, а не принадлежность ИИН.
ЭЦП исключена из текущего запроса по указанию владельца.
МИС: название медицинской системы, документация тестового API и разрешённый доступ.
Подключений к внешней клинике, eGov или Damumed пока нет.
Фактическое использование физического микрофона владельца в QA не проверялось.

ГРАНИЦЫ
Это исследовательский прототип. Не вводить настоящие ИИН и медицинские данные.
Демо-утверждение, учебный зачёт и текстовый экспорт не создают действительную справку,
направление или юридически значимую подпись. Нет клиентов, продаж или измеренной
клинической экономии времени QadamX. Внешние исследования не выдаются за наши результаты.
Перед клиническим внедрением нужны персональные аккаунты, организационные правила,
согласия, восстановление доступа, проверка безопасности и клиническая валидация.

РАЗРАБОТКА
web/ — страницы; worker/index.mjs — вход; worker/data.mjs — API и права.
db/schema.ts и drizzle/ — схема и миграции D1. Привязка DB в .openai/hosting.json.
Сборка: node scripts/build.mjs. Локальный сервер: node scripts/preview.mjs --demo.
Локальная база .local-data/ не публикуется. Демопароль preview не подходит к сайту.
Проверки: node tests.cjs; node scripts/auth-tests.mjs;
node scripts/workspace-tests.cjs; node scripts/data-tests.mjs.
Runtime secrets: QADAMX_ACCOUNTS и QADAMX_SESSION_SECRET.
Cookie HttpOnly/Secure/SameSite Strict, срок 8 часов. version аккаунта отзывает сессии.
Хеш паролей PBKDF2 SHA-256, 100000 итераций, случайная соль.
Миграции применяются хостингом до публикации Worker, не каждым API-запросом.
