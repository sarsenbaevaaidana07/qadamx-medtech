## Что это

Врач заполняет готовую форму документа прямо на сайте, а не копирует текст из Word. Каждая строка опирается на фрагмент исходного разговора с пациентом. Документ сразу выходит на бланке в PDF или Word.

Студенты тренируются на 1 268 синтетических клинических случаях, а наставники оценивают их работы по пяти критериям и видят прогресс.

| Роль | Что делает |
|---|---|
| 🩺 **Врач** | Заполняет шаблон, ссылается на источник, экспортирует документ, отвечает на заявки пациентов |
| 🎓 **Студент** | Тренируется на случаях, отправляет работу наставнику, видит свой прогресс |
| 🧑‍🏫 **Наставник** | Оценивает работы по рубрике 1–5, оставляет комментарии, следит за группой |
| 🛡 **Администратор** | Создаёт аккаунты, сбрасывает пароли, смотрит журнал действий и заявки на пилот |
| 👤 **Пациент** | Отправляет заявку без регистрации и проверяет статус по QR-коду |

## Возможности

- **Шаблоны вместо Word.** 5 шаблонов с полями, автоподстановка даты, номера карты и врача.
- **Опора на источник.** У каждого поля номера фрагментов разговора; AI-черновик возвращает цитаты.
- **Экспорт.** PDF через печать браузера и Word (.doc) на бланке, с водяным знаком «учебный документ».
- **Версии.** История изменений и сравнение двух версий по словам.
- **Время.** Таймер активного времени до утверждения и страница «Время оформления».
- **Обучение.** Маршрут студент → наставник → комментарий или учебный зачёт; рубрика 1–5 по пяти критериям и графики прогресса.
- **Профили.** Фото или иллюстрированный аватар, страница «Наставники и врачи».
- **Администрирование.** Аккаунты, сброс паролей, журнал действий, заявки на пилот.
- **Пациент.** Гостевая заявка, ответ врача по секретному коду и QR-код статуса.
- **Оценка качества.** 635 отложенных случаев, базовые линии ROUGE, числа, отрицания (`npm run evaluate`).
- **Два языка.** Казахский и русский во всём интерфейсе, переключение в один клик.

Распознавание речи, SMS/ИИН и внешняя медицинская система пока не подключены. AI работает только после добавления серверного ключа `ANTHROPIC_API_KEY`.

## Архитектура

<img src="docs/screenshots/architecture.jpg" alt="Архитектура" width="100%">

- **Браузер.** Без фреймворков, без ключей и паролей на клиенте. Шрифт Inter встроен.
- **Cloudflare Worker.** API, роли и проверка доступа к каждой записи; пароли в PBKDF2, подписанная сессия, лимиты запросов.
- **D1.** Документы, версии, оценки, профили, журнал, заявки. Миграции в `drizzle/`.
- **Claude API.** AI-черновик только через сервер, ответ в структурном JSON с номерами источников (модель `claude-opus-5-5`).

## Запуск локально

Нужен Node.js 22.19 или новее (локальный адаптер использует `node:sqlite`).

```sh
npm ci
npm run build
npm test
npm run preview
```

Откройте http://127.0.0.1:8765 . Локальные демо-логины: `admin`, `doctor`, `mentor`, `mentor2`, `mentor3`, `student`, `student2`, `student3` (вымышленные люди), пароль `Local-preview-only-2026`. Они работают только в локальном preview. Настоящие пароли сайта в репозиторий не включены.

Локальная база создаётся в `.local-data/` и исключена из Git. В кабинете врача сначала назначьте наставника студенту, после этого студент сможет отправить работу на проверку.

## Развёртывание

Сайт работает на Cloudflare Workers и D1. Конфигурация в `wrangler.jsonc`, сборка создаёт `dist/server/index.js`.

```sh
npm run build
npx wrangler d1 migrations apply DB --remote
npx wrangler deploy
```

Секреты задаются через `wrangler secret put`:

| Секрет | Зачем |
|---|---|
| `QADAMX_ACCOUNTS` | Аккаунты с хешами паролей. Загружайте через `node scripts/set-accounts.mjs`: пароли вводятся скрыто, на сервер уходят только хеши. Нужна хотя бы одна запись с ролью `admin`. |
| `QADAMX_SESSION_SECRET` | Ключ подписи сессий |
| `ANTHROPIC_API_KEY` | Необязательно, включает AI-черновик |

Для своего развёртывания нужен собственный аккаунт Cloudflare, своя база D1 (замените `database_id`) и свои секреты.

## Данные и права

Включены 1 268 обучающих примеров и 640 исходных отложенных примеров из [Clinical Visit Note Summarization Corpus](https://github.com/microsoft/clinical_visit_note_summarization_corpus). После удаления точных пересечений и повторов набор для оценки содержит 635 примеров. Это английские синтетические примеры, не реальные пациенты. Аудио в исходном корпусе отсутствует.

Отложенные примеры лежат в репозитории для воспроизводимости, но не включаются сборщиком в веб-приложение. Не используйте их для обучения, если планируете независимую оценку.
