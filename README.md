# QadamX MedTech

Исследовательский прототип медицинского документооборота с отдельными кабинетами врача, студента и наставника. Интерфейс на русском и казахском.

[Работающий сайт](https://qadamx-medtech-research-1109.happyburr1.chatgpt.site)

## Возможности

- Вход по логину и паролю, серверные роли и проверка доступа к каждой записи.
- Серверные документы, история версий, назначения наставников и уведомления.
- Учебный маршрут: студент → наставник → комментарий / учебный зачёт.
- Гостевая заявка → врач → ответ по секретному коду.
- Ручной редактор с исходным диалогом и отдельным эталоном.
- Локальная запись аудио до 60 секунд.
- **v5:** 5 шаблонов документов (консультация, SOAP, выписка, направление, справка) с полями вместо свободного текста; дата, № карты и врач подставляются сами.
- **v5:** экспорт на бланке: PDF (через печать браузера) и Word (.doc), водяной знак «учебный документ».
- **v5:** цитаты источника у каждого поля, AI-черновик с номерами фрагментов (нужен серверный ключ `ANTHROPIC_API_KEY`, модель `claude-opus-5-5`).
- **v5:** таймер активного времени до утверждения и страница «Время оформления»; сравнение версий по словам.
- **v5:** оценка наставником по 5 критериям (1–5) и графики прогресса студентов.
- **v5:** профили с фото (или иллюстрированный аватар), страница «Наставники и врачи».
- **v5:** администратор: создание аккаунтов, сброс пароля, отключение, журнал действий, заявки на пилот.
- **v5:** главная страница с демо-туром на 2 минуты и формой «Хочу в пилот»; QR-код статуса заявки пациента.
- **v5:** страница «Оценка качества»: 635 отложенных случаев, базовые линии (ROUGE, числа, отрицания). Пересчёт: `npm run evaluate`, с AI: `npm run evaluate -- --ai 50`.

Распознавание речи, SMS/ИИН и внешняя медицинская система пока не подключены. AI работает только после добавления серверного ключа. Это учебный прототип: не вводите настоящие медицинские данные. Экспорт и учебный зачёт не создают действительную справку или направление. Клиентов, продаж и измеренной клинической эффективности пока нет.

## Запуск

Нужен Node.js 22.19 или новее (локальный адаптер использует node:sqlite).

```sh
npm ci
npm run build
npm test
npm run preview
```

Откройте http://127.0.0.1:8765 . Для локального preview логины `admin`, `doctor`, `mentor`, `mentor2`, `mentor3`, `student`, `student2`, `student3` (вымышленные люди), пароль `Local-preview-only-2026`. Это только локальные тестовые аккаунты. Настоящие пароли сайта в репозиторий не включены.

Локальная база создаётся в `.local-data/` и исключена из Git. В кабинете врача сначала назначьте наставника студенту. После этого студент сможет отправить работу на проверку.

| Каталог | Содержание |

| `web/` | Интерфейс, учебные примеры и уведомления об авторстве |

## Данные и права

Включены 1 268 обучающих примеров и 640 исходных отложенных примеров из [Clinical Visit Note Summarization Corpus](https://github.com/microsoft/clinical_visit_note_summarization_corpus). После удаления точных пересечений и повторов набор для будущей оценки содержит 635 примеров. Это английские синтетические примеры, не реальные пациенты или клиенты QadamX. Аудио в исходном корпусе отсутствует.

Отложенные примеры доступны в репозитории для воспроизводимости, но не включаются сборщиком в веб-приложение. Не используйте их для обучения, если планируете независимую оценку.

Условия данных и атрибуция: [CC BY 4.0](web/attribution/LICENSE), [NOTICE](web/attribution/NOTICE), [README авторов](web/attribution/README.md). Дополнительный источник MTSAMPLES: https://www.mtsamples.com . Условия данных не являются лицензией на собственный код проекта. Отдельная открытая лицензия на код владельцем пока не выбрана.

Для повторного импорта оригинального ZIP:

```sh
python prepare_data.py /path/to/clinical_visit_note_summarization_corpus-main.zip
```

Полный PDF AMA и извлечённые из него страницы не включены; в проекте сохранено описание использованного источника.

## Развёртывание

Рабочая версия использует Cloudflare Worker и D1 через Sites. Сборка создаёт `dist/server/index.js`; миграции находятся в `drizzle/`. Нужна привязка `DB` и серверные секреты `QADAMX_ACCOUNTS`, `QADAMX_SESSION_SECRET`. Для v5: добавьте в `QADAMX_ACCOUNTS` хотя бы одну запись с ролью `admin`, а для AI — секрет `ANTHROPIC_API_KEY`. Миграция `drizzle/0002_little_mojo.sql` добавляет таблицы профилей, аккаунтов, журнала, заявок и метаданных документов. Существующий идентификатор Sites сохранён в `.openai/hosting.json`; это не ключ доступа. Для самостоятельного развёртывания нужен собственный проект и собственные секреты. GitHub сам по себе не запускает сервер и базу.
